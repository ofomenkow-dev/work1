# Методика ROBOT Lab

Новая учебная реализация на Python по описанию функций DOS-пакета.
Исходников и описания двоичного формата RCS в исходном архиве нет.
Численное совпадение с RCS.EXE не установлено. Исходный архив без изменений
находится в legacy/ROBOT.zip. Старые программы не запускаются.

## Кинематика и единицы

Координаты и размеры: мм. Время: с. Углы в интерфейсе: градусы,
в расчётах: радианы. Обобщённые координаты: q1, q2, q3, z.

СКАРА: три поворотных звена и вертикальная ось.
x = L1*cos(q1) + L2*cos(q1+q2) + L3*cos(q1+q2+q3).
y = L1*sin(q1) + L2*sin(q1+q2) + L3*sin(q1+q2+q3).
Диапазон q3: ±360°.

Декартовая схема: x=q1, y=q2, z=q4, q3 — ориентация схвата.
Диапазоны x: 0…Xmax, y: 0…Ymax, z: 0…Zmax.

Цилиндрическая схема: x=q2*cos(q1), y=q2*sin(q1), z=q4.
q2 — радиус, q3 — ориентация схвата, диапазон q3: ±180°.

Основной вид — сверху на горизонтальную плоскость XY: X вправо, Y вверх.
Высота Z=start_z фиксируется для всего опыта. Вертикальное перемещение не
задаётся и не моделируется. Старое поле end_z игнорируется. Все поворотные
оси перпендикулярны XY; ориентация схвата — угол в этой плоскости.

Рабочая область показана приближённой выборкой XY для всех допустимых
ориентаций q3. Это не точная граница, расчёт объёма или проверка столкновений.
Для фиксированной ориентации доступна лишь часть показанной области.

Ориентация задания phi задаётся в градусах, от −180 до 180°.
Для СКАРА из целевой точки вычитается (L3*cos(phi), L3*sin(phi)),
решается обратная задача двух звеньев, q3=phi-q1-q2. Проверяются обе
конфигурации локтя. Для цилиндрического робота q3=phi-q1; для декартового q3=phi.
Розовая стрелка показывает фактическую ориентацию: q1+q2+q3 для СКАРА,
q1+q3 для цилиндрического робота, q3 для декартового. Из-за независимых
приводов во время движения фактическая ориентация может отклоняться от задания.

## Таблица пар

От 2 до 200 пар. Равные интервалы между строками: duration/(число строк−1).
Каждый интервал должен быть не короче шага расчёта и периода контроллера.
Формат X/Y: координаты в мм; Z берётся из высоты плоскости. В контурном режиме
линейно интерполируются X и Y, затем решается обратная кинематика.

Суставный формат: СКАРА — q1 и q2 в градусах; цилиндрическая схема —
q1 в градусах и радиус q2 в мм; декартовая — линейные q1 и q2 в мм.
Интерполируются введённые координаты, затем выполняется прямая кинематика.
Это сохраняет выбранную пользователем конфигурацию локтя; обратная задача
не подменяет отрицательное q2 положительным. q3 вычисляется из заданного phi.

В позиционном режиме первая пара задаёт начальное положение. Сразу после
начала каждого интервала задание скачком переходит к следующей паре.
След не обязан соединять конечные положения прямой. Строки с недостижимыми
координатами или выходом за ограничения суставов отклоняются до расчёта.

Проверяется достижимость узлов дискретной заданной траектории. Непрерывный
путь между узлами не сертифицируется. В контурных заданиях X/Y разрывы
углов больше pi отклоняются. В явно заданных суставных таблицах направление
определяется самими числами: переход от 140° к −140° проходит через 0°,
а не по кратчайшей дуге. Обход сингулярностей и глобальное планирование не реализованы.

## Управление и вычислительное устройство

Три независимых канала P-регулятора в плоскости XY; Z закреплена:
dq/dt = (Kp/tau)*(q_command - q_feedback).
За шаг h используется alpha = 1-exp(-Kp*h/tau).
При квантовании обратной связи применяется экспоненциальное приращение
по ошибке, измеренной в начале шага. Приращение ограничивается
максимальной скоростью привода и границами координаты.

АЦП/ЦАП: равномерное квантование команды и обратной связи, шаг
(qmax-qmin)/(2^bits-1), округление к ближайшему уровню.
Частота контроллера определяет обновления задания. Задержка равна
числу тактов / частота. Обновления округляются вверх к сетке расчёта,
задержанное задание берётся из предыдущего узла.

Шаг расчёта должен быть не больше периода контроллера. Для сравнений
рекомендуется dt <= 1/(10*f); уменьшайте шаг до сходимости результатов.
Для точного совпадения времён обновления выбирайте целое отношение
периода к dt. За текущий шаг интегрируется команда с прошлого шага:
новая команда не действует на уже прошедший интервал.

Разрядность — разрешение АЦП/ЦАП, а не архитектура CPU. Частота —
частота управления, а не тактовая частота процессора. Массы, инерция,
трение, упругость, редукторы и электрическая динамика двигателей
не моделируются. Это упрощённая учебная модель для сравнений,
а не средство инженерной аттестации роботов.

## Режимы и показатели

Позиционный режим: точное начальное положение, при t>0 скачок задания
в конечную точку. Пунктир соединяет точки задания, но не требует
двигаться по прямой. Контурный режим: равномерное задание отрезка или
один полный оборот окружности в XY на заданной высоте плоскости.
Табличное задание описано выше.
Начало круга: (centerX+radius, centerY, startZ). Начало X/Y и конечные
координаты для окружности не используются.

Скорость задания: длина отрезка / длительность или
2*pi*radius / длительность. Ограничения скорости приводов независимы.

Ошибка положения: e=sqrt((x_actual-x_ref)^2+(y_actual-y_ref)^2+(z_actual-z_ref)^2).
Выводятся максимум, СКО=sqrt(mean(e²)) по всем отсчётам и конечная ошибка.
Включён переходный процесс. Контурная ошибка — синхронная ошибка
слежения за заданной точкой, не кратчайшее расстояние до кривой.
Ориентационная ошибка в эти показатели не входит. По Z ошибка равна нулю:
фактическое движение механически ограничено горизонтальной плоскостью.
Вкладка «След XY» показывает пространственный рисунок на плоскости; при
анимации след накапливается до текущего момента. Вкладка «Осциллограммы»
содержит заданные и фактические X(t), Y(t), отдельно от рисунка XY.

CSV: время, заданные и фактические XYZ, ошибка. JSON: все входные
параметры, без массива результатов. После загрузки пересчитайте движение.
При изменении параметров прежние результаты недоступны для экспорта,
пока расчёт не выполнен снова. Недостижимые траектории отклоняются,
а не обрезаются до достижимых координат.
