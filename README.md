# ROBOT Lab · Python

Оконная учебная программа на Python с русским интерфейсом PySide6 (Qt 6)
и графиками Matplotlib. После установки работает без подключения к сети.

Возможности:
- СКАРА, декартовая и цилиндрическая схемы, геометрия и ограничения.
- Вид сверху на горизонтальную плоскость XY, анимация с нарастающим следом схвата.
- Таблица пар X/Y или суставных координат; поворот схвата в плоскости XY.
- Настройки управления, скорости, разрядности, частоты и задержки.
- Позиционный режим; контур по таблице пар, отрезку или окружности.
- Осциллограммы X(t), Y(t) и заданные значения для сравнения.
- График погрешности, максимум, СКО и конечная ошибка.
- Сохранение/загрузка JSON, экспорт CSV, сохранение графиков.

## Установка на Windows

Установите Python 3.12 (64 bit). Распакуйте архив, откройте PowerShell
в папке с этим README и выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m robot_lab
```

После установки можно запускать двойным щелчком `start_windows.bat`.
Внешний Python и установка зависимостей необходимы; это не готовый exe.

## Linux/macOS

Рекомендуется Python 3.11/3.12 и графическая рабочая сессия.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m robot_lab
```

Или после установки: `sh start_unix.sh`.
Linux требует системные библиотеки Qt/X11/OpenGL. На Debian/Ubuntu обычно
нужны libegl1, libopengl0, libxcb-cursor0, libxkbcommon-x11-0 и зависимости XCB.
При сообщении об отсутствующей библиотеке установите её пакетным менеджером.

Проверки выполнены в Linux с Python 3.12 и Qt offscreen, без дисплея.
Нативный запуск в Windows/macOS не проверен. Облако без рабочего стола
подходит для разработки и тестов, но не показывает интерактивное окно.

## Первая работа

1. Выберите схему и задание «Таблица пар» (установлено по умолчанию).
2. Выберите формат: «Координаты X / Y, мм» или «Суставные координаты q₁ / q₂».
3. Введите пары построчно. Кнопки «＋ Строка», «− Строка» меняют число точек;
   «Пример» заполняет таблицу для выбранного формата и схемы. При смене формата
   значения не пересчитываются автоматически — проверьте единицы или выберите пример.
4. Задайте высоту Z (одна на весь рисунок), ориентацию схвата φ и длительность.
5. Нажмите «Рассчитать движение» и «Анимация»: звенья вращаются в горизонтальной
   плоскости, а схват постепенно вычерчивает след XY. Розовая стрелка — ориентация схвата.
6. На вкладке «Осциллограммы» сравните X(t) и Y(t), на вкладке «Погрешность» — ошибку.
7. Измените разрядность, задержку или скорость и сравните результаты.
8. Сохраните проект JSON и результаты CSV. В папке `examples/` есть готовые проекты
   для каждой схемы: координатные (`*-xy.json`) и суставные (`*-joint.json`).

В контурном режиме пары соединяются линейно в выбранных координатах.
В суставном формате СКАРА это углы q₁/q₂ в градусах; цилиндрический робот:
угол в градусах / радиус в мм; декартовый робот: q₁/q₂ в мм.
По угловым парам след вычисляется прямой кинематикой и обычно является кривой.
Время между соседними строками одинаковое. В позиционном режиме задание
ступенчато переключается к следующей паре. Окружность доступна в контурном режиме.

Все рисунки выполняются при постоянной Z. В старых проектах поле `end_z`
сохраняется для чтения, но больше не управляет высотой: используется `start_z`.

Для частоты 100 Гц рекомендуется шаг 0,001 с. Начальный шаг 0,01 с
даёт быстрый демонстрационный расчёт; уменьшайте его для проверки сходимости.

## Тестирование

Численные тесты не требуют Qt:

```sh
python -m unittest discover -s tests -v
```

Проверка GUI без дисплея, из папки проекта (Linux):

```sh
QT_QPA_PLATFORM=offscreen PYTHONPATH=. .venv/bin/python tests/smoke_gui.py
```

## Исходная DOS-программа и ограничения

В ROBOT.zip нет исходников: только RCS.EXE, справка и двоичные файлы RCS.
Это новая реализация перечисленных учебных функций на Python с упрощённой
моделью приводов. Совпадение расчётов со старым решателем не подтверждено.
Импорт старых `.RCS` не реализован: формат не документирован.
Исходный архив сохранён без изменений в `legacy/ROBOT.zip`.

Формулы, единицы и ограничения: `docs/MODEL.md`. Пример интерфейса:
`docs/screenshot.png`. Расчёты: `robot_lab/model.py`; UI: `robot_lab/app.py`.
В эту поставку входят все исходники, тесты, документация и исходный DOS-архив.

Обновлённая поставка использует горизонтальную плоскость XY и табличное задание движения.
